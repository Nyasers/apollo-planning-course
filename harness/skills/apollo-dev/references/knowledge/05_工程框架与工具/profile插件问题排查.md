**A:**尝试切换网络或者使用手机热点

## Q:如何判断自己的插件下载成功

#### Q:如何判断自己的插件下载成功

**A:**成功下载插件后会在～/.apollo 目录下有dreamview的目录，检查是否有该目录。如果没有该目录，检查~/.apollo目录是否有用户读写权限，若没有，使用以下命令赋予权限。赋予权限后重新下载。

```bash
sudo chown 用户名 .apollo
```

## Q:执行了插件安装命令，但是dreamview上没有显示插件可以下载的资源

#### 插件可以下载的资源

**A:**该问题可以按照如下流程定位问题原因

确保安装插件的命令是在docker容器内部执行。
确认自己使用的是Apollo 8.0包管理版本，目前的插件只支持包管理版本。
确认自己是否成功下载了插件。
确认自己的网络状况是否良好。

Q:判断自己的插件启动是否成功

#### Q:判断自己的插件启动是否成功

** A:** 启动dreamview

```bash
aem bootstrap
```
使用如下命令查看是否有studio_connector node节点，如果有说明插件启动成功

```bash
cyber_node list
```

Q:插件启动正常，安装正常，但是没有可下载资源的情况

**A:**是否存在一个apollo studio账号多个人使用的情况，如果存在这种情况，需要验证一下自己的插件证书是否已过期，插件每下载一次会更新一份用户身份验证证书，如果有多个人下载的情况，同一账号只有最近下载插件的用户可以正常使用插件，其他用户账号会存在证书过期情况导致下载场景失败。

#### Q:使用插件中下载云端场景失败

**A:**下载场景可能是logsim场景（不含起点、终点），本地只能识别带起点、终点的场景

## Q:个人云端场景下载失败

**A：**需要排查两个问题：

1、创建个人场景集时需要选择线下场景。

2、df -lh命令检查系统磁盘空间大小是否足够，是否存在磁盘空间不足的问题
