# 体感指标说明与计算方法

> 体感指标在场景通过的基础上评估行驶舒适度，直接影响赛事综合得分。

---

## 一、体感指标总览

| 指标 | 符号 | 推荐阈值 | 单位 | 计算来源 |
|------|------|---------|------|---------|
| 纵向加速度 | aₓ | ≤ 3.0 m/s² | m/s² | 规划速度轨迹一阶差分 |
| 纵向加速度变化率（Jerk） | jₓ | ≤ 4.0 m/s³ | m/s³ | 规划速度轨迹二阶差分 |
| 横向加速度 | aᵧ | ≤ 2.0 m/s² | m/s² | 曲率 × 速度² |
| 急刹车次数 | — | 越少越好 | 次 | 减速度 > 4.0 m/s² 的帧数统计 |

> 阈值来源：`config.yaml` 中 `eval_*` 字段，可根据赛事最新规则调整。

---

## 二、各指标详解

### 2.1 纵向加速度（aₓ）

**定义**：车辆沿行进方向的加速度，正值为加速，负值为制动。

**计算方法**：
```
aₓ[i] = (v[i+1] - v[i-1]) / (2 * dt)
```
其中 `v` 为速度序列，`dt` 为时间步长（Planning 默认 0.1s）。

**超限表现**：
- 急加速（aₓ > 3.0）：绿灯起步过猛、出路口加速过快
- 急制动（aₓ < -3.0）：在障碍物前紧急刹车

**优化方向**：
- 调整 `lon_acceleration_bound`（上限）
- 调整 `max_deceleration`（制动上限）

---

### 2.2 纵向加速度变化率（Jerk，jₓ）

**定义**：加速度的变化率，反映加速/制动是否平顺。Jerk 越大，乘客越有"被甩"的感觉。

**计算方法**：
```
jₓ[i] = (aₓ[i+1] - aₓ[i-1]) / (2 * dt)
```

**超限表现**：
- 速度突变（如碰到障碍物后突然急刹）
- 频繁刹车-加速-刹车循环

**优化方向**：
- 调整 `lon_jerk_bound`
- 提前减速，避免在障碍物前突然刹停

---

### 2.3 横向加速度（aᵧ）

**定义**：车辆垂直于行进方向的加速度，反映转弯舒适度。

**计算方法**：
```
aᵧ = κ × v²
```
其中 `κ` 为轨迹曲率，`v` 为车速。

**超限表现**：
- 高速急转弯
- 借道变道速度过快

**优化方向**：
- 调整 `lat_acceleration_bound`
- 变道时适当降速

---

### 2.4 急刹车次数

**定义**：行驶过程中减速度绝对值超过 4.0 m/s² 的次数（帧级别统计）。

**计算方法**：
```python
hard_brake_count = sum(1 for a in accel_series if a < -4.0)
```

**优化方向**：
- 提高感知到障碍物后的提前减速距离（`stop_distance_obstacle`）
- 降低跟车速度，增加跟车距离

## 三、体感指标速查卡片

```
纵向加速度  aₓ  ∈ [-3.0, +3.0] m/s²     超限 → 看急刹/急加速
纵向 Jerk   jₓ  ∈ [-4.0, +4.0] m/s³     超限 → 看速度突变
横向加速度  aᵧ  ∈ [-2.0, +2.0] m/s²     超限 → 看高速变道/转弯
急刹车次数      尽量为 0 次              超限 → 看障碍物处理逻辑
```

---

## 四、如何定位体感超限位置

1. 提取速度/加速度序列（见 `../02_数据分析/01_轨迹指标提取脚本.md`）
2. 找到 `aₓ` 或 `jₓ` 超限的时间戳
3. 在 cyber record 回放中跳转到对应时刻，观察场景状况
4. 对应优化 → 见 `../04_优化指引/00_体感优化参数映射.md`
