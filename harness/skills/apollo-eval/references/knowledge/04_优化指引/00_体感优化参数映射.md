# 体感优化参数映射

> 根据 `extract_metrics.py` 或评估报告中的超限指标，快速定位需要修改的配置参数文件。

---

## 一、快速映射表

| 超限指标 | 对应参数 | 配置文件路径（容器内） | 调整方向 |
|---------|---------|-------------------|---------|
| 纵向加速度 max > 3.0 | `lon_acceleration_bound` | `profiles/default/modules/planning/planning.pb.txt` | 减小上限值 |
| 纵向减速度 < -3.0 | `max_deceleration` | `profiles/default/modules/planning/planning.pb.txt` | 减小绝对值 |
| 纵向 Jerk max > 4.0 | `lon_jerk_bound` | `profiles/default/modules/planning/planning.pb.txt` | 减小 |
| 横向加速度 > 2.0 | `lat_acceleration_bound` | `profiles/default/modules/planning/planning.pb.txt` | 减小 |
| 急刹车次数多 | `stop_distance_obstacle` | `profiles/default/modules/planning/planning.pb.txt` | 增大（提前减速） |
| 急刹车次数多 | `crosswalk_statics_obs_stop_dist` | `profiles/default/modules/planning/traffic_rule_config.pb.txt` | 增大 |
| 变道 Jerk 高 | `lane_change_prepare_length` | `profiles/default/modules/planning/lane_change.pb.txt` | 增大（增长变道距离） |

> 路径以 `/apollo_workspace/` 为根目录，`profiles/default/` 为软链目录（执行 `aem profile use default` 后生效）。

## 二、纵向加速度优化

### 问题：急加速（aₓ > 3.0 m/s²）

**常见场景**：绿灯起步、出路口加速

```protobuf
# profiles/default/modules/planning/planning.pb.txt
default_task_config: {
  task_type: SPEED_BOUNDS_PRIORI_DECIDER
  speed_bounds_priori_decider_config: {
    total_time: 7.0
    # 调小此值以限制加速度
    lon_acceleration_bound: 2.5   # 默认通常为 4.0，推荐 2.0~3.0
  }
}
```

### 问题：急制动（aₓ < -3.0 m/s²）

**常见场景**：障碍物前紧急刹车、跟车距离不足

```protobuf
# 增大障碍物前的停止距离（提前开始减速）
default_task_config: {
  task_type: DECIDER_RULE_BASED_STOP
  rule_based_stop_decider_config: {
    stop_distance: 4.0     # 默认约 1.0，增大让车提前减速
  }
}
```

## 三、Jerk 优化

### 问题：纵向 Jerk 超限（> 4.0 m/s³）

**常见原因**：速度曲线不平滑，存在突变

```protobuf
# profiles/default/modules/planning/planning.pb.txt
default_task_config: {
  task_type: PIECEWISE_JERK_SPEED_OPTIMIZER
  piecewise_jerk_speed_config: {
    acc_weight: 10.0        # 增大以更重视加速度平滑
    jerk_weight: 1000.0     # 增大以约束 Jerk（默认约 200）
    kappa_weight: 1.0
  }
}
```

### 问题：变道 Jerk 超限

```protobuf
# profiles/default/modules/planning/lane_change.pb.txt
lane_change_prepare_length: 8.0    # 增大（默认约 4.0），给更长的变道准备距离
lane_change_min_length: 6.0
```

---

## 四、横向加速度优化

### 问题：转弯/变道时 aᵧ > 2.0 m/s²

**根本原因**：高速 + 大曲率

```protobuf
# 增大曲率权重，使路径更平滑
default_task_config: {
  task_type: PIECEWISE_JERK_PATH_OPTIMIZER
  piecewise_jerk_path_config: {
    kappa_weight: 5.0        # 增大（默认约 1.0）约束曲率变化
    dkappa_weight: 200.0     # 增大以约束曲率变化率
  }
}
```

同时检查速度限制，变道时是否有限速触发：
```protobuf
lane_change_max_speed: 6.0    # m/s，在 lane_change.pb.txt 中
```

## 五、急刹车优化

### 问题：在人行道/障碍物前急刹

```protobuf
# traffic_rule_config.pb.txt 中针对 crosswalk（人行道）
traffic_rule_config: {
  rule_id: CROSSWALK
  crosswalk: {
    stop_strict_l_distance: 6.0       # 人行道侧向感知距离，增大更保守
    start_watch_timer_distance: 20.0  # 提前多远开始关注人行道（增大=更早准备）
    max_stop_deceleration: 3.5        # 最大减速度（减小=更温和）
  }
}
```

### 问题：障碍物前急刹

```protobuf
# planning.pb.txt 中的 st_bounds_decider
default_task_config: {
  task_type: ST_BOUNDS_DECIDER
  st_bounds_decider_config: {
    total_time: 7.0
    # 增大安全时距，更早开始减速
    min_stop_distance_obstacle: 5.0   # 默认约 2.0
  }
}
```

## 六、常见参数文件位置速查

```
profiles/default/modules/planning/
├── planning.pb.txt               # 主配置（加速度、Jerk、速度限制）
├── traffic_rule_config.pb.txt    # 交通规则插件参数（人行道、停止线等）
├── lane_change.pb.txt            # 变道参数
├── decider_creep.pb.txt          # 蠕行（低速通过路口）参数
└── scenario/
    ├── lane_follow_config.pb.txt   # 跟随车道场景
    ├── intersection/               # 路口场景
    └── valet_parking/              # 泊车场景
```

## 七、修改参数后必须执行

```bash
# 编译后必须重新加载 profile，否则参数不生效
aem profile use default

# 验证参数是否生效（可选）
cat profiles/default/modules/planning/planning.pb.txt | grep -A3 "lon_acceleration_bound"
```
