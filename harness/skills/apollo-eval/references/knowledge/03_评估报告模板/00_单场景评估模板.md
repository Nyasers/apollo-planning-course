# 单场景评估模板

> 复制本模板，填写每个场景的仿真结果，用于记录和对比优化进展。

---

## 基本信息

| 字段 | 内容 |
|------|------|
| 场景名称 | （例：借道绕行 / 人行道避让 / 交汇路口减速） |
| 评估日期 | YYYY-MM-DD |
| 代码版本/分支 | （例：`git log --oneline -1` 的结果） |
| profile 版本 | （例：`profiles/default` 最后修改时间） |
| record 文件 | （例：`data/bag/crosswalk_test_20260511.record`） |

---

## 性能指标

| 指标 | 结果 | 说明 |
|------|------|------|
| 场景通过 | ✅ 通过 / ❌ 未通过 | 车辆是否到达终点且无碰撞 |
| 完成时间 | — s | 从场景启动到到达终点 |
| 碰撞次数 | 0 | 与任何物体碰撞的次数 |
| 速度违规 | 无 / 有（说明） | 是否超速或违规通行 |
| Planning 稳定性 | 稳定 / 有崩溃/卡顿 | 模块运行状态 |
