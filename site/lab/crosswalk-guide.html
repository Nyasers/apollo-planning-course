人行道避让真实实验

按照真实 Harness 和 Apollo 仿真界面完成一轮人行道场景实验。每一步都对应实际按钮与界面，截图用于辅助定位；实际运行和报告仍由本地 Harness 完成。

打开本地 Harness 打开 DreamView 查看实验报告
One complete run 0 / 11 完成后可回到实验报告页导入 report.json，查看评分、证据和 AI 解释。

Step by step

从启动到复盘

建议按顺序完成，每一步都以实际界面为准
  1. 01

    Open Harness

    打开本地 Harness

    在实验中心打开 Harness。首次点击需要允许浏览器打开 Apollo_Harness 本地应用。

    启动并打开 Harness已启动？直接打开
    如果浏览器没有响应，先检查本地启动器是否安装，再重新尝试。
    HARNESS
  2. 02

    Start runtime

    启动 Linux 与仿真环境

    点击 Harness 中的启动仿真。系统会启动 WSL/Ubuntu、Docker、Apollo 容器和 DreamView，页面期间可能处于等待状态。

    启动需要几秒到数分钟；不要重复点击，也不要关闭等待中的页面。
    RUNTIME
  3. 03

    SimControl

    进入仿真并选择 Scenario Sim

    DreamView 打开后，进入 SimControl，选择 scenario_sim。这是本轮真实场景运行的入口。

    打开 DreamView
    DREAMVIEW
  4. 04

    Map

    选择人行横道地图

    选择人行道场景对应的地图。地图和场景必须匹配，否则停车距离、行人和停止线数据都会失去意义。

    不要为了“先跑起来”随意更换地图；先确认地图名称和场景一致。
    SCENARIO
  5. 05

    Modules

    打开全部规划控制模块

    启动 Planning、Control 及其他场景需要的模块。确认主界面没有明显报错，再进入下一步。

    如果模块启动失败，先看 Harness 的环境检查和技术日志，不要直接开始录制。
    MODULES
  6. 06

    Record

    回到 Harness，开始录制

    回到 Harness，在录制步骤勾选“实际运行”，点击“开始录制”。录制会采集 planning、control、localization 等核心 channel。

    录制由人工结束，不设固定 25 秒限制。先让车辆完成一次完整的人行横道运行。
    打开 Harness 录制
    RECORD
  7. 07

    Run

    回到仿真界面开始运行

    回到 DreamView/SimControl 启动车辆运行，观察车辆接近人行横道、识别行人、减速停车和继续通行。

    本实验的主评分规则是车头到人行横道边界 1.5—2.0 m 内停车；以最终报告中的停车距离为准。
    RUN
  8. 08

    Stop record

    停止录制并生成 channel 报告

    车辆完成后回到 Harness，人工点击“结束并保存”，再点击“生成报告”。检查 record、CSV、图表和 channel 汇总是否生成。

    不要为了凑时长继续录制；以一次完整场景运行的数据为准。
    打开 Harness 生成报告
    REPORT
  9. 09

    Self-eval

    生成自评并导出报告

    依次点击“生成自评”和“导出”，生成 report.json、report.md、selfeval.md 和证据文件。

    报告的完整数据必须来自同一轮 record；导出后再进入网站复盘。
    SELF-EVAL
  10. 10

    AI review

    接入 DeepSeek 解释报告

    在 Harness 的 DeepSeek 设置中保存自己的 API Key，只保存在本机。随后围绕报告提问，例如“为什么没有通过？”或“下一轮先改什么？”。

    不要把 API Key 发到网页、文档或聊天中；AI 只解释证据和提出建议，不替代学生确认与重新运行。
    AI REVIEW
  11. 11

    Web report

    在网站查看证据和结论

    回到实验报告页，导入本轮 report.json，查看场景分、停车距离、过程证据和 AI 建议。确认页面显示的是同一轮实验数据。

    打开实验报告查看 AI 使用引导
    WEB REVIEW

Evidence first

报告只认同一轮数据

不要拼接不同 record、不同场景或不同时间的结果。

AI boundary

AI 不替代判断

模型给解释和建议，学生确认操作，教师保留最终评价权。

Safety

不要跳过环境检查

环境未就绪时先修复，不要用演示结果代替真实实验。
