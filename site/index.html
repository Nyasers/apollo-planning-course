01

你将完成什么

不是先背完 C++，而是沿着一条真实项目链路，
把环境、代码、数据和报告连起来。

  1. 01

    跑通 Apollo 仿真环境

    在 Ubuntu / WSL2 中启动 Docker、AEM、Apollo 容器和 DreamView，完成第一次场景运行。

  2. 02

    读懂 Planning 主线

    从输入到轨迹，理解 Scenario、Stage、Task 如何组织一次规划，并把 C++ 语法放回真实源码。

  3. 03

    完成一次可复核实验

    录制核心 channel，查看 TTC、Jerk 和急刹，形成一份可以复盘的实验报告。

工具链

  • Ubuntu / WSL2
  • Docker · AEM
  • DreamView · SimControl
  • Cyber Record
  • Apollo Planning / C++
  • Apollo_Harness

工具是路径，不是目的。每一课只引入完成当前任务所需的工具。
