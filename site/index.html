Apollo Planning Self-Study

先跑起来，再读懂规划。

这不是一份从函数细节开始的“劝退教程”。路线从 Linux 仿真环境出发，先建立 Apollo 与 Planning 的整体地图，再逐步进入 Scenario、Task 和读懂代码所需的 C++。实验中心新增 Apollo Claw AI 辅助闭环，把环境检查、日志定位、record、评分和报告串成可追溯证据链。

进入 AI 实验中心 查看 AI 辅助闭环 准备本地环境 从第 00 课开始
  1. 准备 Linux 环境虚拟机、双系统或 WSL2，先让 Apollo 跑起来。可学习
  2. 建立 Apollo 地图知道 Planning 在哪里，以及 Scenario、Stage、Task 的关系。可学习
  3. 看懂一轮 Planning从输入到轨迹，只看主线，不先钻算法。下一步
  4. 深入 Scenario 与 Task围绕常见场景和任务读源码。规划中
  5. 补齐 C++ 生存技能指针、引用、类和继承，只为读懂项目服务。规划中
  6. 完成小型实战修改一个简单任务并运行验证。规划中

Learning Model

每一课都让学生自己走完闭环

先理解场景，再看源码，再做小实验，最后用自测题确认自己是否真的会了。没有老师现场补充，所有关键概念、命令和答案都写进页面。

MAIN LINE

围绕项目，而不是围绕语法书

先看 Apollo 如何接收数据、选择场景、执行任务，再把指针、引用、类和继承放回真实源码里解释。学 C++ 的目的是读懂项目，不是先背完一门语言。

  • 先看输入和输出，再看实现。
  • 先看 Scenario 和 Task，再看复杂优化。
  • 算法数学放到进阶，不影响入门过关。
01

环境是入口

虚拟机、双系统或 WSL2 只是路线差异，最终都必须能启动 Docker、AEM 和 DreamView。

02

任务认知

Scenario 决定“遇到什么情况”，Stage 决定“进行到哪一步”，Task 负责“具体做什么”。

AI-assisted Lab

AI 辅助实验闭环

Apollo Claw 以 env、dev、test、eval 四类技能贯穿实验前、中、后。网页展示 AI 介入点、证据链、优化前后对比和能力画像；真实执行、DeepSeek 调用和报告由本地 Harness 完成。

Source Discipline

环境跟指南，源码跟官方

安装过程依据 Apollo EDU PnC 安装指南；代码阅读以官方 ApolloAuto/apollo 固定提交为准。当前提交为 Apollo 9.0。

开始前请记住

Apollo 仿真运行在 Linux 上。Windows 用户必须先准备 Ubuntu 虚拟机、双系统或 WSL2；WSL2 虽然方便，但 Docker、GUI 和端口兼容性需要单独验证。

建议的自学顺序

先完成第 00 课安装检查，再读第 01 课全景地图。环境没有跑通时可以做静态阅读，但不要假装完成运行实验。
