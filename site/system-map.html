System Map · Extension

系统模块全景

课程主线以 Planning 为入口，但完整实验还包含感知、定位、预测、控制和底盘执行。本页补齐 PnC 上下游的结构关系、关键组件和 Cyber RT channel。

01
感知与定位

把传感器观测转化为障碍物和车辆位姿。

02
预测与规划

估计未来状态，生成安全、舒适、可执行的轨迹。

03
控制与执行

把轨迹变成油门、制动和转向指令，再由底盘执行。

01

六个核心模块

模块名和组件名来自 Apollo 9.0 固定源码基线 d53aa3d。本页只做系统级导读，具体算法以对应源码和课程单元为准。

P

感知 Perception

输入：相机 / LiDAR / Radar

相机检测、激光雷达检测和多传感器融合组件输出障碍物位置、速度、尺寸和类别。

CameraDetectionBevComponentLidarDetectionComponentmulti_sensor_fusion
L

定位 Localization

输入：GNSS / IMU / map

MSF、NDT、RTK 等定位组件融合传感器和高精地图，发布车辆位姿、速度与姿态。

MSFLocalizationComponentNDTLocalizationComponentRTKLocalizationComponent
F

预测 Prediction

输入：PerceptionObstacles

PredictionComponent 结合障碍物、定位和自车轨迹，输出未来轨迹与行为意图。

PredictionComponentPredictionObstacles
E

规划 Planning

输入：障碍物 / 位姿 / 预测

PlanningComponent 通过 Scenario、Stage、Task 组织交通规则、路径和速度规划，输出 ADCTrajectory。

PlanningComponentScenarioManagerTask
C

控制 Control

输入：轨迹 / 位姿 / Chassis

ControlComponent 是 TimerComponent，读取规划轨迹、定位、底盘和 Pad 消息，计算控制指令。

ControlComponentPID / LQRControlCommand
V

底盘与车辆执行

输入：ControlCommand

Canbus/Chassis 网络接收控制指令并回传车辆状态，形成闭环；DreamView 用于观察和调试。

ChassisCanbusDreamView

03

源码核对位置

以下路径用于课程阅读和后续实验定位，运行前请以本地固定基线为准。

  1. 01

    感知

    modules/perception/*_component.h，重点看检测节点、融合节点和 PerceptionObstacles 输出。

  2. 02

    定位与预测

    modules/localization/msf/msf_localization_component.h、modules/prediction/prediction_component.h。

  3. 03

    规划与控制

    modules/planning 的 Scenario/Stage/Task 与 modules/control/control_component/control_component.h。

阅读顺序

  • 先看 channel 和消息类型
  • 再看组件 Init / Proc
  • 再看算法和配置
  • 最后对照 record 与 DreamView

不要一开始陷入算法细节，先建立输入—输出—组件—证据的关系。

课程连接：本页补充感知、定位、预测和控制的全景；具体代码阅读仍从第 01–03 课、第 10–16 课和第 19 课进入。
