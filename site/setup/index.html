Harness Quick Start

Harness 下载后如何配置和使用

推荐在 Windows 宿主机运行 Harness，由它调用 WSL/Apollo；也可以直接在 WSL/Ubuntu 内运行。

推荐 · 一键配置

解压后双击“一键配置Harness.cmd”

脚本会自动检查 Python、创建本地配置目录、安装 apollo-harness:// 启动器并创建桌面快捷方式。

  1. 从首次使用向导下载并解压 Harness。
  2. 双击压缩包根目录的 一键配置Harness.cmd。
  3. 回到首次使用向导，点击“启动并打开 Harness”。
  4. 在 Harness 面板内配置 DeepSeek Key、检查环境并启动仿真。
去首次使用向导
手动启动方式（仅在自动配置失败时查看）
推荐

Windows 宿主机运行

  1. 解压 Harness 到固定目录，例如 C:\ApolloClaw\harness。
  2. 确认 Windows 已安装 Python 3.9+。
  3. 在 PowerShell 中进入 Harness 目录并安装启动器。
  4. 回到首次使用向导点击“启动并打开 Harness”。
  5. 浏览器打开 http://127.0.0.1:8765/，在面板中配置 DeepSeek Key。
cd C:\ApolloClaw\harness
python --version
powershell -ExecutionPolicy Bypass -File scripts\install-harness-launcher.ps1

WSL / Ubuntu 内运行

  1. 将 Harness 解压到 Ubuntu 目录。
  2. 运行安装脚本，默认使用包内 skills/。
  3. 启动 Harness 服务。
  4. 在 Windows 浏览器访问本地端口。
cd ~/apollo-claw-harness
bash scripts/install-harness.sh
python3 -m apollo_claw serve --port 8765

如需单独指定技能目录，可设置 APOLLO_SKILLS_SOURCE。

1. 服务启动/health 返回 200
2. 环境检查Linux / Docker / Apollo / DreamView 分层显示
3. 模型连接在面板保存并测试 DeepSeek Key
4. 开始实验进入场景并开始 record
首次使用：启动仿真、环境检查、record 和 DeepSeek Key 配置都在 Harness 面板内完成，不需要在终端手动执行 aem 命令或编辑 .env。建议返回 首次使用向导，按照“配置确认 → 准备材料 → 检查环境 → 开始实验”的顺序执行。API Key 只保存在本地，不写入网页或 Git。

One-click Launcher

Windows 一键启动本地 Harness

浏览器不能直接启动本地程序，需要通过一次性的本地启动器注册 apollo-harness:// 协议。

cd C:\path\to\apollo-planning-course\harness
powershell -ExecutionPolicy Bypass -File scripts\install-harness-launcher.ps1
安装后：回到实验页点击“启动并打开本地 Harness”。浏览器首次会询问是否打开 Apollo_Harness，选择“打开”即可；Harness 已在运行时，也可以直接访问 http://127.0.0.1:8765/。如果应用内浏览器没有弹出确认框，请用 Edge 或 Chrome 打开本页再点击。
