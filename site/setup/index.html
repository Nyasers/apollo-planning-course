First Start

首次启动和 Harness 检查

镜像导入后，先启动 Apollo 仿真，再启动本地 Harness。

# 1. 进入 Ubuntu 终端
cd ~/application-pnc

# 2. 启动 Apollo 容器并进入
aem start
aem enter

# 3. 启动 DreamView
aem bootstrap start --plus

# 4. 新开终端，启动 Apollo Claw Harness
~/apollo-claw/scripts/start-harness.sh

# 5. 浏览器访问本地实验台
# http://127.0.0.1:8765/

DeepSeek Key

本地模型配置

DeepSeek Key 只保存在本地环境，不进入网页、Git 或实验报告。

mkdir -p ~/.apollo-claw
cat > ~/.apollo-claw/.env <<'EOF'
DEEPSEEK_API_KEY=sk-your-key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
EOF
chmod 600 ~/.apollo-claw/.env

允许

  • 本地保存 Key
  • 本地调用 Harness
  • 本地保存 record 和报告

禁止

  • 把 Key 写进网页
  • 把 Key 提交到 Git
  • 把隐私数据上传到公开平台
