01

四模块课程结构

课程保持 21 个单元不变，用四个模块建立从系统环境到综合实验的学习路径。

模块单元学时核心目标AI 技能
M1 系统与仿真环境00–038建立 Apollo、Cyber RT、Planning 与 Scenario/Stage/Task 的系统地图。apollo-env / apollo-dev
M2 C++ 与 PnC 基础04–0916补齐阅读真实 Task、配置和插件代码所需的 C++ 能力。apollo-dev
M3 Scenario 与 Task10–1624理解场景切换、Stage 执行、路径、速度和交通规则。apollo-dev / apollo-eval
M4 工程化与综合实验17–2012完成配置、编译、新增 Task、日志调试和限速实战。apollo-test / apollo-eval
02

实验教学安排

单次实验按 8 个阶段执行；24 步是完整项目建设路线，不要求学生一次完成全部内容。

A

课前：建立任务与环境

完成课程预习、环境检查和学习目标确认。产出：预习记录、doctor.json。

B

课中：运行、诊断与录制

进入人行道避让场景，观察问题，使用 apollo-dev/test 定位并录制核心 channel。

C

课后：评分、优化与报告

使用 apollo-eval 解释指标，完成一次优化复跑，提交 report.json / report.md。

D

评价：证据与教师复核

过程证据、实验报告、AI 使用记录和教师评价共同构成最终成绩。

课程边界：当前已开放人行道避让单场景 MVP；交通灯、自主泊车和完整 24 步按建设路线逐步开放。

进入实验中心 →
03

评价与证据

课程不是“看完页面即完成”，而是以可复查的本地实验产物作为学习证据。

  1. 01

    过程评价

    环境检查、场景运行、record、channel 盘点、日志定位和 AI 使用记录。

  2. 02

    结果评价

    TTC、纵向/横向加速度、Jerk、急刹、通行效率和实验报告。

  3. 03

    教师复核

    本地自评不是官方分数；教师结合证据、报告和操作过程完成最终评价。

提交物

  • doctor.json
  • record / channel_summary.csv
  • plots / score.json
  • report.json / report.md
  • 个人反思
